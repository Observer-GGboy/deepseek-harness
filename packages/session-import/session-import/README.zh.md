# @deepseek-ai/dsh-session-import

[English](README.md) | 中文

安全导入外部 Session 的 Service Definition。`SessionImportRegistry` 拥有 `ctx.sessionImports`；Codex 与 Claude Code 是独立的 Service Provider。共享辅助函数在不打开 transcript 正文的情况下递归发现元数据，拒绝符号链接，并在来源大小、单行大小、可见字节、可见消息和工具数量预算内流式读取一个被选中的 JSONL 文件。

捕获前缀固定为开始读取时的文件大小。捕获开始后的追加内容会被忽略；替换、截断、中段变更、格式错误的完整记录、时间戳乱序、重复记录与不受支持的必要结构都会故障关闭。末尾不完整记录会被忽略并报告。提供方输出的是中立不可变快照，绝不是 `SessionEvent`。

可见文本进入快照前会进行凭据脱敏。隐藏指令、推理、工具参数、工具结果、附件、环境值和来源 transcript 路径在中立约定中都没有字段。

## 模型体验

### 导入的历史上下文

#### 模型看到什么

只有经过脱敏的可见用户／助手文本，以及不含正文、不可执行的工具活动摘要；消费方会在用户确认后把快照转换为原生 `SessionEvent` 值。

#### Token 影响

首次继续请求模型时，导入的可见文本会消耗上下文 token。被排除的记录不消耗 token。

#### KV Cache 影响

导入 Session 会创建新的提示词前缀；它不会复用外部产品的缓存身份。

## 已知限制与暂缓事项

- 共享捕获格式目前只有 JSONL；未来的非 JSONL 提供方必须实现等价的稳定性与预算保证。
- 凭据脱敏覆盖常见 key 与授权值形状，不保证识别以任意自然语言写出的秘密。
- 提供方兼容性刻意采用故障关闭；供应商新增必要记录结构时，需要显式更新解析器。
